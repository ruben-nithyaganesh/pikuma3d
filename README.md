## pikuma3d
3d renderer following the course by https://pikuma.com

https://github.com/user-attachments/assets/4c7d3c65-6257-484d-9a4f-3a775102aa68



## Running the code
For SDL build:
```
./build/sdl/sdl_build.sh && ./build/sdl/sdl_renderer
```

For Windows build:
```
build\win32\win32_build.bat && build\win32\win32_renderer.exe
```

All commands should be performed from the project root directory
